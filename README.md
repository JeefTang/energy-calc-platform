# 节能测算Pro - 工业节能测算平台

## 项目简介
节能测算Pro是一个专业的工业节能测算平台，提供多种工业设备的节能效果计算和分析功能。

## 功能模块
1. **柱塞泵节能测算** - 基于泵效率提升和变频调速技术
2. **风机节能测算** - 风机系统节能效果计算
3. **水泵节能测算** - 水泵系统节能分析
4. **磨机节能测算** - 磨机设备节能评估
5. **历史记录** - 测算数据保存和查看

## 技术特点
- 纯前端实现，无需后端服务
- 响应式设计，支持移动端访问
- 实时计算，即时显示结果
- 数据可视化展示
- 技术方案一键生成

## 计算公式

### 柱塞泵模块
- 电机功率 = 平均流量 × 压差 ÷ 3.6 ÷ 泵的效率 × 1.1
- 综合节电率 = (原设备功率 - 新设备功率) ÷ 原设备功率 × 100%

### 风机模块
- 根据风机功率和运行时间计算节能效果

### 水泵模块
- 基于水泵流量、扬程和效率计算

### 磨机模块
- 根据磨机功率和负载率计算

## 使用说明
1. 选择相应的设备模块
2. 输入设备参数
3. 点击"开始测算"按钮
4. 查看计算结果和技术方案
